# 🩸 Banco de Sangre Mobile

Aplicación móvil Android para la gestión de un Banco de Sangre.

El objetivo del proyecto es digitalizar y facilitar la gestión de pacientes, turnos, donaciones y evaluaciones de aptitud, centralizando la información necesaria para el seguimiento de los donantes.

## 📱 Estado del proyecto

🚧 **En desarrollo**

Actualmente se encuentran implementadas las primeras interfaces de usuario y la navegación inicial de la aplicación.

## 🛠️ Tecnologías utilizadas

- Java
- Android Studio
- XML
- Material Design
- Git
- GitHub

## 🏗️ Arquitectura

El proyecto está organizado separando las responsabilidades en diferentes capas:

- `view` — Interfaces y Activities
- `controller` — Controladores de la aplicación
- `service` — Lógica de negocio
- `repository` — Acceso y gestión de datos
- `model` — Entidades y modelos del sistema

## ✅ Funcionalidades implementadas

- Pantalla de inicio de sesión
- Pantalla principal
- Accesos rápidos
- Listado de pacientes
- Ficha individual del paciente
- Navegación entre las diferentes pantallas

## 🔜 Próximas funcionalidades

- Gestión de turnos
- Alta y modificación de pacientes
- Registro de donaciones
- Historial de donaciones
- Evaluación de aptitud para donar
- Restricciones temporales y permanentes
- Fecha estimada de próxima donación
- Integración con API REST
- Persistencia de datos

## 🎯 Objetivo

Desarrollar una solución que permita reemplazar procesos manuales por un sistema digital, manteniendo un historial organizado de los pacientes y sus donaciones.
